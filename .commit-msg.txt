Phase 2.3: World-space lane evaluation

Introduces the evaluation layer that combines SegmentSequence
(Phase 1), LaneSection (2.1), and Polynomial3 (2.2) to produce
world-space lane positions. Pure evaluation — no sampling, no
mesh, no allocations.

New file: lane_geometry.hpp
  Separation of concerns:
    lane_engine.hpp = data model
    lane_geometry.hpp = math (world-space evaluation)

  LanePoint struct:
    - position (Point2D): world-space x, y
    - tangent (Vec2): unit tangent (direction of travel)
    - normal (Vec2): unit normal (left = 90° CCW from tangent)
    - heading (double): heading angle in radians
    - laneOffset (double): lateral offset from reference line (right-positive)

  evaluateLaneCenter(road, laneId, s):
    World-space center of lane at arc-length s.
    Uses active LaneSection at s, or synthesized legacy section.
    C¹ continuous if geometry and width polynomials are C¹.
    O(log N) per call, no allocations.

  evaluateLaneBoundary(road, laneId, outer, s):
    World-space position of lane edge (inner or outer).

  evaluateLaneAtOffset(road, lateralOffset, s):
    Most general form — arbitrary lateral offset.

  World-space equation:
    Pworld = positionAt(s) - normalAt(s) * lateralOffset
  (normalAt returns left-positive; laneOffset is right-positive)

Tests (22 new doctest, 361 total, 3108 assertions):
  Straight road (6):
    - Lane +1 at constant -y offset
    - Lane -1 at constant +y offset
    - Center lane at reference line
    - Heading/tangent/normal correct
    - Inner/outer boundary edges
    - Legacy synthesis (no explicit LaneSection)
  Arc road (3):
    - Outer lane has larger radius (left turn)
    - Right turn reverses inner/outer
    - Lane offset constant along arc
  Spiral road (2):
    - Lane center continuous (no discontinuities)
    - Left/right symmetric about center
  Bezier road (2):
    - Normal direction consistent (unit, perpendicular to tangent)
    - Lane offset constant
  Mixed road (2):
    - Continuous across line→arc boundary
    - Variable width taper moves center toward reference line
  evaluateLaneAtOffset (3):
    - Matches evaluateLaneCenter
    - Zero offset = reference line
    - Negative offset = left
  4-lane road (2):
    - All lane centers on straight road
    - All boundaries on straight road
  Performance (1):
    - 1000-segment road, 1000 evaluations (target <2ms release)
  Multiple sections (1):
    - Lane count changes at section boundary

All 130 vitest tests pass (no regression).
