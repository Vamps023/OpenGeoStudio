Phase 12: Intersection generation + fix duplicate engine headers

Added road intersection generation using the C++ road engine's
geo::generateIntersection function. This enables junction creation
between two crossing roads with fillet corners and trim lines.

RoadEngineService::generateIntersection:
- Takes two roads and computes their intersection
- Returns polygon boundary, fillet arc points, trim points,
  boundary intersections, corner radius, and intersection angle
- Implemented in RoadIntersection.cpp (separate TU) to avoid
  duplicate geometry.hpp definitions

Engine header deduplication:
- Replaced root geometry.hpp with redirect to public/geometry.hpp
- Replaced root road.hpp with redirect to public/road.hpp
- Added GEO_FILLET_ARC_DEFINED guard to prevent duplicate filletArc
  definitions between arc.hpp and skia_arc.hpp
- These fixes resolve the long-standing include conflict that
  prevented intersection.hpp from being used alongside road_engine.hpp
