Phase 1.6: Adaptive sampling (recursive midpoint displacement)

Implements curvature-based adaptive sampling for all GeometrySegment
subclasses. Purely additive — no existing files modified.

Named constants (from architecture doc Appendix B):
  MAX_GEOM_ERROR_HORIZONTAL = 0.25 m (default sampling tolerance)
  MAX_GEOM_ERROR_VERTICAL   = 0.1 m
  GEOM_TOLERANCE            = 0.2 m (min distance between vertices)
  MAX_GEOM_LENGTH           = 50 m
  MIN_GEOM_LENGTH           = 0.1 m
  ADAPTIVE_MAX_DEPTH        = 20 (recursion depth limit)

Algorithm: recursive midpoint displacement
  1. Start with minSamples (default 2) uniformly distributed
  2. For each adjacent pair, compute chord midpoint vs actual curve point
  3. If chord error > maxError, subdivide and recurse
  4. Stop when: error < tolerance, OR depth >= ADAPTIVE_MAX_DEPTH,
     OR sample count >= maxSamples
  Naturally produces more samples in high-curvature regions.

Control-flow guards (same discipline as math guards):
  - ADAPTIVE_MAX_DEPTH (20): prevents stack overflow on pathological inputs
  - maxSamples (default 10000): caps total output size
  - Zero-length segment: returns single point without recursion
  All three guards have explicit tests.
