Fix map only showing half screen and mouse events not reaching OpenGL

Two issues fixed:

1. Map only visible on half screen:
   - Root cause: MapLibre and OpenGL widgets were in a QVBoxLayout,
     stacking them vertically (each got half the height) instead of
     overlapping.
   - Fix: Use QStackedLayout with StackAll mode so both widgets
     overlap and fill the entire viewport area.

2. Can't draw on map in 2D mode:
   - Root cause: MapLibre widget was intercepting mouse events before
     they reached the OpenGL widget.
   - Fix: Set Qt::WA_TransparentForMouseEvents on the MapLibre widget
     so all mouse events pass through to the OpenGL widget on top.
     The OpenGL widget handles all drawing interactions while the
     map is purely a visual background.
