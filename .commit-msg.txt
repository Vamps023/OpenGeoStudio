Fix O3DE project path — auto-detect valid project on startup

The registry had the old broken project path D:/git/OpenGeoStudio3D
saved from a previous session. Even after updating the registry,
the running app would overwrite it on exit with the stale value.

Fix: add findO3DEProject() that auto-detects a valid O3DE project
by checking for project.json. On startup, if the saved path is
empty or invalid (project.json doesn't exist), it auto-detects
and saves the correct path.

Detection order:
  1. D:/git/OpenGeoStudio3D-SDK (SDK project, correct)
  2. D:/git/OpenGeoStudio3D (from-source, may not exist)

Also cleared the stale registry setting while the app was not
running, so it starts fresh with the correct SDK project path.
