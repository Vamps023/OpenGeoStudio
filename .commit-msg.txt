Fix O3DE Editor launch — add --project-path argument

O3DE Editor requires --project-path <path> argument to know which
project to open. Previously the path was passed as a bare argument
which the editor didn't recognize, causing it to exit immediately
with code 2.

Fix:
  Before: Editor.exe D:/git/OpenGeoStudio3D-SDK
  After:  Editor.exe --project-path D:/git/OpenGeoStudio3D-SDK

Also updated placeholder text to show the correct SDK project path.
