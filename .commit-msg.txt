Fix crash when opening recent project with road data

The crash happened because loadFromPath() was called during
project open, before LaneMaker's OpenGL context was initialized
(the Road Studio page wasn't visible yet).

Fix: defer road file loading until Road Studio workspace is
actually activated. The project open stores the .xodr path in
m_pendingRoadFile, and when the user switches to Road Studio,
the file is loaded via QTimer::singleShot(100ms) to ensure the
OpenGL context is ready.

Additional safety:
  - Check for empty files before loading
  - Null-check g_mapViewGL before calling update()
  - If Road Studio is already active when project opens, load
    immediately (context is ready)

Build: SUCCESS
