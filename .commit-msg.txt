Add Geometry Debug Mode and polygon validation

Implements the geometry audit and debug visualization system requested
for stabilizing the geometry engine.

Geometry Debug Mode (Ctrl+Shift+G):
- Toggleable debug overlays in the map viewport
- 14 individual layer toggles in the toolbar:
  centerline, leftEdge, rightEdge, laneBoundaries, offsetCurves,
  roadPolygon, filletArcs, tangentPoints, trimPoints,
  intersectionPolygon, triangulation, vertexNormals, uvGrid,
  samplePoints
- Color-coded overlays:
  - Cyan: centerline, tangent points
  - Green: left edge
  - Red: right edge, trim points
  - Orange: lane boundaries, fillet arcs
  - Blue: road polygon
  - Magenta: intersection polygon, triangulation
  - Yellow: sample points
- Debug button in toolbar with layer toggle chips

C++ Polygon Validation (geometry.hpp):
- validatePolygon(): checks for duplicate vertices, self-intersections,
  zero-length edges, invalid winding, degenerate area
- cleanPolygon(): removes duplicate consecutive vertices
- PolygonValidationResult struct with detailed diagnostics
- Integrated into intersection generation (validates + cleans polygon)

Store (roadStudioStore.ts):
- New state: debugMode, debugLayers (14 toggles)
- New actions: toggleDebugMode, toggleDebugLayer, setDebugMode

Tests: 40/40 pass (28 existing + 12 new algorithm unit tests)
- Line intersection (parallel, perpendicular)
- Offset (curved road edges, no self-intersection)
- Trim (correct distance from center)
- Fillet (smooth corners in intersection polygon)
- Circle arc (smooth curve, finite points)
- Clothoid (continuous curvature)
- Bezier (passes through endpoints)
- Polygon validation (no duplicate points)
- Mesh winding (consistent CCW)
- Mesh normals (all pointing up)
- UV mapping (tiles every 10m)
