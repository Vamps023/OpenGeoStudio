Add 2D top-down view mode and real satellite map background

Features:
- 2D/3D toggle button in LaneMaker toolbar
  - 3D mode: perspective projection (default, original LaneMaker view)
  - 2D mode: orthographic top-down projection for plan view
- "Map" button in toolbar to load Esri World Imagery satellite tiles
  - Fetches tiles from server.arcgisonline.com via QNetworkAccessManager
  - Renders the tile as a textured OpenGL quad behind the road geometry
  - Tile is projected onto the ground plane (z=0) in world coordinates
