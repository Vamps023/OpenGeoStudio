Add QGIS-inspired map subsystem (CRS, tile math, transforms)

Studied QGIS source code (D:/git/QGIS) and ported key map
subsystem patterns to create a proper coordinate/tile
infrastructure. No PROJ dependency — uses built-in formulas
for the common EPSG:4326 ↔ EPSG:3857 transforms.

New files in src/core/map/:

1. MapRectangle.hpp — Geographic extent class
   Inspired by QgsRectangle. Supports normalize, scale, grow,
   intersect, contains, combineWith.

2. CoordinateReferenceSystem.hpp — CRS representation
   Inspired by QgsCoordinateReferenceSystem. Supports
   EPSG:4326 (WGS84 lat/lon) and EPSG:3857 (Web Mercator).

3. CoordinateTransform.hpp — CRS transformations
   Inspired by QgsCoordinateTransform. Built-in formulas for
   EPSG:4326 ↔ EPSG:3857 (lonLatToMercator, mercatorToLonLat).
   No PROJ library dependency needed.

4. TileMatrix.hpp — Standard XYZ tile scheme
   Inspired by QgsTileMatrix/QgsTileMatrixSet from qgstiles.cpp.
   Web Mercator tile math: tileExtent, tileRangeFromExtent,
   mapToTileCoordinates, scaleToZoomLevel, zoomLevelForExtent.

5. MapToPixel.hpp — Screen ↔ World conversion
   Inspired by QgsMapToPixel. Uses QTransform matrix for
   world→screen and screen→world conversion with Y-axis flip.

6. TileCache.hpp — In-memory LRU tile cache
   Inspired by QgsTileCache. Thread-safe QCache<QUrl, QImage>
   with 256 tile limit.

7. XyzTileProvider.hpp — XYZ tile URL template + download
   Inspired by QGIS formatXYZUrlTemplate() and QgsWmsProvider
   XYZ mode. Supports {x}, {y}, {-y} (TMS), {z} placeholders.
   Integrates with TileCache for cached requests.

8. MapSubsystem.hpp — Umbrella header

9. map_tests.cpp — 31 doctest tests covering all classes
