Phase 1.7: SegmentSequence + s/t coordinate system

Implements SegmentSequence (task 1.7 of Phase 1 — Geometry Kernel Refactor).
New file: st_coords.hpp. Purely additive — no existing files modified.

Design (per user review):
- Non-owning view: stores const GeometrySegment* pointers. RoadV2 will
  own the unique_ptr<GeometrySegment> objects. This avoids duplicating
  clone/copy/move/lifetime logic between SegmentSequence and RoadV2.
- API mirrors GeometrySegment: evaluateDS(s), positionAt(s), tangentAt(s),
  normalAt(s), curvatureAt(s), headingAt(s). From the outside,
  SegmentSequence IS one continuous geometry — same interface, no
  "global" prefix.
- Binary search O(log N) for globalS → (segment, localS) using
  cumulative length offsets.
- clampS() centralizes clamping; all eval methods use it.
- validateContinuity() returns std::vector<ContinuityError> with
  diagnostics (segmentA, segmentB, positionError, headingError), not
  bool — so the editor can highlight the offending segment.
- Empty sequence: assert in debug, not silent (0,0) — hiding bugs is
  worse than crashing in development.
- projectToST() intentionally omitted — not declared. A stub returning
  {0,0} is dangerous (someone could use it). When Phase 3 arrives, the
  compiler will remind us it doesn't exist. Compile error > silent bug.

st_coords.hpp contains:
  - SegmentSequence class (non-owning view, 215 lines)
  - positionAtST(seq, s, t) free function: lateral offset
    t positive = left (CCW from tangent), using normalAt(s)
  - headingAtST(seq, s, t) free function: heading is independent of t
    for rigid cross-section, included for lane direction queries

SegmentSequence API:
  - Constructor: SegmentSequence(vector<const GeometrySegment*>)
  - numSegments(), totalLength(), segment(idx)
  - clampS(s) — clamp to [0, totalLength]
  - globalSToLocal(s) → {segmentIndex, localS} — binary search
  - evaluateDS(s, x, y, h), positionAt(s), tangentAt(s), normalAt(s),
    curvatureAt(s), headingAt(s)
  - validateContinuity(posTol, headingTol) → vector<ContinuityError>
