Phase 5: Train Studio — 2D track editing with line and arc tools

Implemented Train Studio as a 2D-only workspace for railway track design:

Data model (TrainTypes.hpp):
- Track with control points, gauge (1.435m standard), color, kind (line/arc)
- ControlPoint with lat, lon, z
- Selection, HistorySnapshot, Tool (select/line/arc)
- JSON serialization for all types

State management (TrainStudioStore):
- Track CRUD: startNewTrack, addControlPoint, updateControlPoint,
  deleteControlPoint, deleteTrack, clearAll
- Selection management
- Undo/redo (50 snapshot limit)
- Arc drawing workflow: startArc, finishArc, cancelArc
- XML export to Oksygen Track Mesh Builder format (simplified)
- Tool switching (select/line/arc)

2D viewport (TrainViewport2D):
- MapLibre satellite map background
- Transparent QPainter overlay for track rendering
- Track lines with gauge-scaled width and rail visualization
- Control points with selection highlighting
- Arc preview with start point and direction arrow
- Pan (shift+drag/middle mouse)
- Select tool with hit-testing
- Line tool creates new tracks
- Arc tool: 2-click workflow (start + end)

Toolbar:
- Select (V), Line (L), Arc (A) tools
- Undo/Redo with keyboard shortcuts
- Delete selected, Clear all
- Export XML (Oksygen network format)

Note: OSM railway import (Overpass API) and XML validation are not
yet ported — they require network access and XML schema validation
which will be added in Phase 6.
