Phase 2.7: Road Mesh Generator — renderable geometry

Introduces the mesh generation layer that converts LaneNetwork and
RoadMarkNetwork into renderable triangle strips. No lane math, no
sampling, no marking logic — just tessellation of already-defined
geometry.

New file: road_mesh_generator.hpp
  Separation of concerns:
    lane_engine.hpp          = Data model
    lane_geometry.hpp        = Evaluation
    lane_sampling.hpp        = Sampling
    lane_network.hpp         = Persistent lane network
    road_mark_generator.hpp  = Mark generation
    road_mesh_generator.hpp  = Mesh generation (THIS FILE)

  MaterialType enum:
    - Asphalt, WhiteMarking, YellowMarking
    - Curb, Shoulder, Sidewalk, Grass (future)
    - Unknown (fallback)
    - materialTypeName() for serialization

  MeshVertex struct:
    - position (Point3D): world-space (x, y, z)
    - normal (Vec3): unit normal (0, 0, 1) for flat roads
    - uv (Vec2): texture coordinates

  MeshSection struct:
    - material, materialName
    - vector<MeshVertex> vertices
    - vector<uint32_t> indices
    - merge() for combining sections of same material

  RoadMesh struct:
    - vector<MeshSection> sections (split by material)
    - findSection(), getOrCreateSection()
    - totalVertices(), totalTriangles()

  MeshGenParams:
    - zHeight (default 0)
    - uvScale (1m = 1 UV unit)
    - markingElevation (0.01m above pavement)
    - generateMarkings flag

  Pavement generation (generateRoadMesh):
    - One triangle strip per lane
    - Uses boundary samples from LaneNetwork
    - CCW winding from above (Z-up)
    - UV: U = s (arc-length), V = lateral offset
    - Lanes processed independently (per-lane LOD/editing)
    - Only drivable lanes get asphalt material

  Marking generation (generateMarkingMesh):
    - Solid lines: continuous strip along marking polyline
    - Dashed lines: one quad per dash, interpolated at exact
      dash boundaries (not dependent on sample density)
    - UV: U = distance along marking, V = 0..1 across width
    - Split by color: WhiteMarking, YellowMarking
    - Markings elevated slightly above pavement (0.01m)

  generateFullRoadMesh: combines pavement + markings
