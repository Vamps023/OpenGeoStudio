Fix LaneMaker Qt resources not loading (shaders, models, icons)

Root cause: Qt resources compiled into a static library (lanemaker.lib)
were being stripped by the linker because nothing in the library
directly referenced the qrc object files. The Q_INIT_RESOURCE() calls
in main.cpp were not sufficient to force inclusion.

Fix: Move qt_add_resources() output from the lanemaker static library
to the OpenGeoStudio executable target. This ensures the qrc object
files are always linked into the final binary.

Resources affected:
- shaders/simple.vert, simple.frag, instanced.vert, texture.frag
- models/jeep.obj, jeep.jpg, cadillac.obj, cadillac.jpg,
  military.obj, military.jpg
- icons/*.png (toolbar, mode buttons, etc.)
