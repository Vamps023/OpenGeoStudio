Fix albedo texture loading with proper OGRE-Next Image2 upload

The previous setTexture(name) approach silently failed because the
albedo file path was not in a registered OGRE resource location.

Now loads albedo via QImage, converts to RGBA8888, creates a manual
TextureGpu with ManualTexture flag, and uploads pixel data via
Ogre::Image2::uploadTo(). This is the correct OGRE-Next pattern
for loading textures from arbitrary file paths.
