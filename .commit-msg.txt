Stabilize geometry engine: fix mesh, tools, intersection, pipeline

Major stabilization effort across the entire geometry pipeline.

C++ Engine Fixes:
- offsetPolyline: replaced simple perpendicular offset with miter-joint
  algorithm (correct for curves, prevents edge self-intersection)
- triangulatePolygon: added winding order normalization (handles both
  CCW and CW polygons via shoelace formula)
- generateRoadMesh: miter-joint edge offsets, arc-length UV mapping
  (tiles every 10m), proper vertex/index counts
- generateIntersectionMesh: local UV mapping (bounding box based)
  instead of world-space
- sampleCenterline: arc-length parameterization (uniform sample density
  regardless of segment curvature)
- sampleCenterline3D: z interpolation by arc length, not by sample index
- buildApproachCenterline: fixed gap issue, always produces valid trim
  point at exact trimDist from center
- generateEdgeBasedPolygon: added corner distance validation, duplicate
  point cleanup
- MeshData struct: added vertexCount, indexCount, triangleCount fields
- generateLaneBoundaries: new function for lane boundary polylines
