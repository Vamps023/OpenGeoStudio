Phase 3.4: Bridge + TS integration for RoadGraph and Junction Builder

C++ Bridge (road_bridge.cpp):
  - Added roadBuildRoadGraph(roads[], intersections[]) → RoadGraph
    Parses roads and intersections, converts to RoadV2, builds RoadGraph
    via buildFromRoads(), serializes nodes/edges to JS objects
  - Added roadBuildJunction(junctionId, roadGraph, laneNetworks) → JunctionResult
    Reconstructs RoadGraph and LaneNetworks from JS objects, builds
    LaneGraph via LaneGraphBuilder::build(), builds junction geometry
    via JunctionBuilder::build(), serializes as typed arrays
  - Both functions registered in InitRoadBridge

IPC Channels (ipcChannels-electron.ts):
  - ROAD_BUILD_ROAD_GRAPH = 'road:buildRoadGraph'
  - ROAD_BUILD_JUNCTION = 'road:buildJunction'

IPC Handler (roadEngineHandler.ts):
  - Handles ROAD_BUILD_ROAD_GRAPH and ROAD_BUILD_JUNCTION
  - Added roadBuildRoadGraph and roadBuildJunction to addon interface

Preload (preload.ts):
  - Added buildRoadGraph and buildJunction to roadEngine API
  - Type declarations and ipcRenderer.invoke bindings

TypeScript Client (roadEngineClient.ts):
  - New types: RoadNodeData, RoadEdgeData, RoadGraphData,
    JunctionStripeData, JunctionMeshData, JunctionResultData
  - NativeRoadEngine.buildRoadGraph() and buildJunction() methods
  - Convenience exports on roadEngine object
  - Window type augmentation for new methods

Native addon rebuilt successfully against Electron 42.5.1 ABI.
