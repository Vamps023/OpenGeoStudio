Phase 14: OSM railway import via Overpass API

Added OSM railway import to Train Studio using the Overpass API.

TrainStudioStore::importOsmRailways:
- Queries Overpass API for railway=rail, railway=light_rail, railway=tram
- Parses OSM XML (nodes + ways) using QXmlStreamReader
- Creates tracks from way nodes with proper lat/lon coordinates
- Reports progress via osmImportStarted/osmImportFinished signals
- Uses QNetworkAccessManager for async HTTP

TrainStudioWidget toolbar:
- Added "Import OSM" button
- Shows bounding box input dialog (south,west,north,east)
- Shows success/failure message when import completes
