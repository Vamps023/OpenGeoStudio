Add O3DE terrain integration — Gem + terrain export

Created OpenGeoStudioTerrain O3DE Gem that provides a
TerrainMeshComponent for importing heightmap + albedo data
from OpenGeoStudio projects into O3DE.

Gem structure:
  Gems/OpenGeoStudioTerrain/
    gem.json
    Code/Source/TerrainMeshComponent.h/.cpp
    Code/Source/stb_image.h (PNG loading)
    Scripts/import_terrain.py (O3DE Python script)

TerrainMeshComponent:
  - Reads 16-bit or 8-bit PNG heightmaps
  - Generates 3D mesh (vertices, normals, UVs, indices)
  - Configurable terrain size and height scale
  - Uses stb_image for file loading (no external deps)
  - Reflects to O3DE Edit Context for in-editor configuration

Qt 3D Studio improvements:
  - Export Terrain button now copies ALL heightmaps + albedo maps
    from the OpenGeoStudio project's Terrain folder to the O3DE
    project's Assets/terrain/ folder
  - Supports both PNG and TIFF formats
  - Copies manifest.json if available
  - Detailed logging of what was exported

  - Qt app: compiled successfully
  - All launchers rebuilt with Gem included
