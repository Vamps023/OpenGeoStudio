Phase 4a-d: Road Studio core — types, store, 2D viewport, toolbar

Implemented the core Road Studio functionality:

Data model (RoadTypes.hpp):
- ControlPoint with bezier handles and segment metadata
- Road with points, width, laneCount, profile
- Selection, HistorySnapshot, Tool, ViewMode, MeshData, Junction
- JSON serialization for all types (matches .ogproj schema)

Coordinate conversion (GeoConvert.hpp):
- geoToLocal / localToGeo (equirectangular projection)
- metersPerPixel / pixelsPerMeter for map scale
- distanceMeters (Haversine)

State management (RoadStudioStore):
- 27 state fields matching the Zustand store
- 35 actions: road CRUD, selection, config, debug, undo/redo
- LaneMaker 3-click workflow state
- 18 debug layers
- Qt signals for all state changes

2D viewport (RoadViewport2D):
- MapLibre satellite map as background
- Transparent QPainter overlay for road rendering
- Road paths with bezier curves and width-scaled strokes
- Control points with selection highlighting
- Bezier handle rendering
- LaneMaker preview with start/end points, direction arrows, distance
- Pan (shift+drag or middle mouse), zoom (scroll)
- Select tool: hit-test control points, drag to move
- Road tool: 3-click LaneMaker workflow

Toolbar (RoadStudioToolbar):
- Select (V) and Road (R) tools
- 2D/3D view mode toggle
- Undo/Redo with keyboard shortcuts
- Snapping toggle and grid size
- Lane width and count configuration
- Demo Road button (200m test road)
- Delete selected, Clear all
- Debug mode toggle (Ctrl+Shift+G)
- C++ engine version indicator
