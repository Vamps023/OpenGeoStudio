Add project delete, fix workspace switch on project open

Three changes:

1. Open project → Terrain workspace
   After opening a project, the app now switches to the Terrain
   workspace instead of the project's saved workspaceId. This
   gives immediate access to the map for area selection.

2. Remove/Delete project from Home screen
   Each recent project row now has a red ✕ button. Clicking it
   shows a confirmation dialog and then:
   - Removes the project from the recent list
   - Deletes the .ogproj file from disk
   - Deletes the entire project folder (with safety check:
     only deletes if a .ogproj file exists in the folder)
   - Closes the project if it's currently open

3. ProjectManager::deleteProject() new API
   bool deleteProject(filePath, deleteFolder=true)
   - Removes from recent list
   - Closes current project if it matches
   - Deletes .ogproj file
   - Deletes project folder if deleteFolder=true
   - Safety: only deletes folder if it contains a .ogproj
   - Publishes "project:deleted" event
