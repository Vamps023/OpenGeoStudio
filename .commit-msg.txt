Fix road drawing in 2D top-down mode (coordinate conversion)

Root cause: PointerOnGround(), PointerDirection(), and PixelLocation()
used perspective math (60° FOV, focal plane distance) which breaks
in orthographic projection. In 2D top-down mode, the camera looks
straight down, so PointerDirection() returned a ray with z≈0 at
screen center, causing division by zero in PointerOnGround() —
all road drawing clicks mapped to NaN/infinity coordinates.

Fixes:
- PointerDirection(): return (0,0,-1) in 2D mode (parallel rays)
- PointerOnGround(): use proper inverse view-projection matrix
  unprojection in 2D mode — maps screen coords to z=0 ground plane
  via NDC unprojection and ray-plane intersection
- PixelLocation(): use forward projection matrix in 2D mode
- wheelEvent(): zoom by moving camera Z in 2D mode (changes ortho
  view size) instead of perspective dolly
- resizeGL(): ortho view size scales with camera Z height so wheel
  zoom actually changes visible area
