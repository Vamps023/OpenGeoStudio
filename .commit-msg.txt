Render map tiles directly in OpenGL — fix 2D map visibility

Root cause: QOpenGLWidget with WA_TranslucentBackground doesn't
reliably composite with widgets behind it in Qt 6. The MapLibre
widget was invisible because the OpenGL widget's FBO wasn't
actually transparent despite alpha=0 clear.

New approach: Render satellite map tiles directly inside the OpenGL
widget as a textured background quad. No widget overlay needed.

Changes:
- loadMapBackground(): fetches a 3x3 grid of Esri World Imagery
  tiles at zoom 16, composites them into a single QImage, uploads
  as OpenGL texture via SetMapBackground()
- toggleViewMode(): auto-loads map tiles when switching to 2D,
  clears map background when switching to 3D
- paintGL(): draws map texture as background in both 2D and 3D modes
- Removed QStackedLayout overlay approach (unreliable transparency)
- MapLibre widget kept but hidden (for potential future use)
- Added alpha buffer to surface format (format.setAlphaBufferSize(8))
- Added resizeEvent override to keep map widget positioned
