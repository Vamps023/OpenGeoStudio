Add configurable lane width and SCANeR-style creation tools

Configurable Lane Width:
- Changed LM::LaneWidth from constexpr to extern double (default 3.25m)
- Added QDoubleSpinBox to LaneConfigWidget (1.5-5.0m, step 0.25m)
- Spinner updates LaneWidth at runtime — affects all road creation
  and rendering immediately
- Increased lane count limit from 4 to 8 per side (matches Electron)
- Label shows "Lane W:" in vertical layout, "W:" in horizontal

SCANeR-style Creation Tools:
- 4 new tool buttons in Road Studio sidebar:
  - "─" Straight Line (already existed)
  - "⤴" Circle Arc — click 2 points, creates constant-radius arc
    using FitArcOrLine (Line if collinear, Arc if curved)
  - "⌁" Polyline — click multiple points, each creates a Line
    segment. Space/Enter to finish, Escape to undo last segment
  - "∼" Bezier — click 2 points, creates smooth cubic bezier
    using FitParamPoly (smoother than default ConnectRays)

Implementation:
- Added Mode_CircleArc, Mode_Polyline, Mode_Bezier to EditMode enum
- Added forceArc, polylineMode, bezierMode flags to RoadCreationSession
- UpdateFlexGeometry checks flags to choose geometry type:
  - forceArc: FitArcOrLine (Line or Arc)
  - bezierMode: FitParamPoly (cubic bezier)
  - polylineMode: forceStraightLine=true, no auto-complete
  - forceStraightLine: direct odr::Line
- Arc and Bezier auto-complete after first segment (2-click workflow)
- Polyline stays open until user presses Space/Enter
- All modes integrated with replay system (SetModeFromReplay + replay_window)
- All modes use LaneConfigWidget for lane configuration
