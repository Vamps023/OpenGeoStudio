Fix road .xodr not saving/loading with Unicode project paths

The road file was not being saved to the project folder because
LaneMaker's saveToPath/loadFromPath used QString::toStdString()
which produces garbage for Unicode paths on Windows (e.g.
OneDrive/文档/...).

Fix: use PathHelper::toTiffPath() to convert Unicode paths to
Windows 8.3 short paths before converting to std::string for
ChangeTracker::Save/Load.

Also added:
  - Logging in saveToPath/loadFromPath (spdlog)
  - Verification in saveProjectState: checks if road.xodr was
    actually created after saveToPath, logs warning if not
  - Logging in loadProjectState via qDebug
  - Better error messages in loadFromPath

Files changed:
  - main_window.cpp: saveToPath and loadFromPath use PathHelper
  - main.cpp: saveProjectState verifies road file creation
