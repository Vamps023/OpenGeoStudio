Phase 2.2: Polynomial width evaluation

Extends the lane data model with polynomial evaluation, derivatives,
and lane width interpolation (pure math, no geometry generation).

Polynomial3 additions:
  - secondDerivative(ds): p''(ds) = 2c + 6d·ds
    Useful for smooth tapers, curvature-aware width, superelevation,
    mesh smoothing. Inexpensive to add while API is still small.
  - isValid(): checks all coefficients are finite (not NaN/Inf)

LaneSection width interpolation (pure lateral math, no world-space):
  - rightWidthAt(ds): sum of right lane widths (id > 0)
  - leftWidthAt(ds): sum of left lane widths (id < 0)
  - boundaryOffset(laneId, ds): lateral offset of lane boundary
    Right: sum(width(1..laneId)), Left: -sum(width(-1..laneId))
  - laneCenterOffset(laneId, ds): lateral offset of lane center
    Right: boundary(laneId-1) + width/2, Left: boundary(laneId+1) - width/2
  - laneInnerEdgeOffset(laneId, ds): boundary closest to center
  - laneOuterEdgeOffset(laneId, ds): boundary farthest from center

Validation enhancement:
  - Checks polynomial coefficients for NaN/Inf
  - Reports "non-finite polynomial coefficients" error

Tests (33 new doctest, 339 total, 2463 assertions):
  secondDerivative (4): constant, linear, quadratic, cubic
  isValid (5): normal, zero, NaN in a/b/d, Inf in b
  Edge cases (8): negative ds, large ds, numerical stability,
    linear widening, linear narrowing, cubic smooth taper,
    randomized evaluation vs explicit formula
  Width interpolation (10): rightWidthAt, leftWidthAt,
    boundaryOffset (right/left), laneCenterOffset (right/left/center),
    inner/outer edge, variable width, variable center offset
  Width continuity (3): constant across sections, taper then constant,
    smooth taper using cubic
  Validation NaN/Inf (3): NaN detected, Inf detected, valid passes
  Multi-lane offsets (2): 4-lane all offsets, 6-lane all offsets

No geometry code, no SegmentSequence integration, no world-space
calculations. Those are 2.3+.

All 130 vitest tests pass (no regression).
