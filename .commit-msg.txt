Phase 1.9: Bridge integration for RoadV2

Exposes the RoadV2 pipeline through the IPC bridge. The TS side
now has access to the new adapter functions without needing to know
which adapter path is used — the bridge dispatches based on
formatVersion.

New IPC methods:
- roadSampleCenterlineV2(road, numSamples?) → Point2D[]
  Uses roadToV2Auto() internally, samples RoadV2 centerline at
  uniform arc-length intervals. Preferred sampling method for new code.
- roadGetAdapterReport(road) → AdapterReport
  Returns diagnostics: exact flag, segment counts, warnings, totalLength
- roadConvertFromV2(road) → Road
  Round-trip: Road → roadToV2Auto() → RoadV2 → roadFromV2() → Road

Bridge changes:
- parseRoad() now parses formatVersion from JS objects
- roadToJs() now serializes formatVersion to JS objects
- segmentMeta parsing/serialization already in place from 1.8.3d
- Version bumped to 2.0.0-road-engine
- road_adapter.hpp included in road_bridge.cpp

TypeScript changes:
- ControlPoint type: added optional segmentMeta field
- Road type: added optional formatVersion field
- SegmentMetadata type: new interface (kind, version, arc/spiral params)
- CppRoad/CppControlPoint: added formatVersion, segmentMeta, id
- toCppRoad(): passes formatVersion and segmentMeta through
- RoadEngineAPI: added sampleCenterlineV2, getAdapterReport, convertFromV2
- AdapterReportResult type: new interface for bridge diagnostics
- Window type augmentation: added new IPC methods

IPC plumbing:
- 3 new channels in ipcChannels-electron.ts
- 3 new handlers in roadEngineHandler.ts
- 3 new preload bridges in preload.ts

Tests (17 new vitest, 130 total):
- Version 2.0.0
- sampleCenterlineV2: line, bezier, legacy (v1), no-formatVersion
- getAdapterReport: exact path, legacy path, arc metadata, clothoid metadata
- convertFromV2: line round-trip, bezier round-trip (handles), arc round-trip (metadata), centerline parity
- segmentMeta serialization: createCircleArc, createClothoidArc, createSegment
- sampleCenterlineV2 vs sampleCenterline: endpoint parity

All 261 doctest + 130 vitest pass (no regression).
