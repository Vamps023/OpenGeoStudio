Fix 2D top-down camera, map quad size, and zoom — 3 root causes

Root cause 1: Camera rotation was 90° around X for 2D top-down mode.
In LaneMaker's coordinate system (Z=up, XY=ground), the default camera
looks down -Z. With NO rotation, camera at (0,0,500) looks straight
down at the XY ground plane — that IS top-down. The 90° X rotation
made the camera look along +Y (horizontal), not down. This broke
both the map view and road drawing.

Fix: Set rotation to 0° in ResetCamera for 2D mode.

Root cause 2: Map texture quad was 10000×10000 world units but the
3×3 tile grid at zoom 16 only covers ~1843 meters. The texture was
stretched 5.4× too much, making it look extremely blurry/wrong.

Fix: Store m_mapWorldExtent = imageWidth * metersPerPixel in
SetMapBackground(). Update quad vertices dynamically in
drawMapBackground() to match the actual tile coverage.

Root cause 3: Ortho projection was only set in resizeGL(), so wheel
zoom (which changes camera Z) didn't actually change the view.

Fix: Update ortho projection every frame in paintGL() based on
current camera Z. Also fixed wheel zoom direction (scroll up =
zoom in = decrease Z) with clamping.
