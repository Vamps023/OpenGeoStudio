Fix stack overflow: remove recursive show() in AnimatedPopupDialog

LaneMaker's AnimatedPopupDialog::showEvent() calls showAnimated(),
which called show(), which triggered showEvent() again — infinite
recursion causing STATUS_STACK_OVERFLOW (0xC00000FD) on startup.

The show() call inside showAnimated() was redundant since
showAnimated() is already called from within showEvent(), meaning
the widget is already being shown. In Qt 6, calling show() inside
showEvent() triggers another showEvent(), unlike Qt 5 where it was
a no-op for already-visible widgets.

Fix: removed the show() call from showAnimated(). The animation
group still starts correctly without it.
