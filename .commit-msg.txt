Replace static map texture with dynamic tile renderer

The old approach composited a fixed 3x3 grid of tiles into a single
768x768 texture, which was blurry and didn't cover the full screen.

New approach: dynamic tile cache that loads tiles on demand based
on the current camera view, like QGIS/Google Maps.

MapViewGL changes:
- MapTile struct: stores individual tile texture + world position
- m_mapTiles: vector of cached tiles
- SetMapCenter(lat, lon): sets geographic center, enables map
- UpdateMapTiles(): calculates visible world bounds, converts to
  lat/lon, determines tile range, requests missing tiles
- requestTile(z, x, y): downloads Esri tile, creates OpenGL texture,
  calculates world position from tile lat/lon
- pruneInvisibleTiles(): removes tiles outside view range
- drawMapBackground(): renders each tile as a separate quad at
  its correct world position
- paintGL(): calls UpdateMapTiles when camera moves significantly
- Geographic helpers: latLonToTile, tileToLatLon, metersPerPixel
- Auto-zoom: reduces zoom level if too many tiles needed

MainWidget changes:
- loadMapBackground() now just calls SetMapCenter()
- Removed old composite image tile fetching code
