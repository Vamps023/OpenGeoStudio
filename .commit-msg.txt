Phase 4g: 3D mesh viewport with OpenGL

Added RoadViewport3D using QOpenGLWidget with direct OpenGL calls
(replaces Three.js renderer in the reference app):

- Road surface mesh rendering from geo::generateRoadMesh data
  (triangles with wireframe overlay)
- Ground plane (1000x1000m)
- Grid helper (50m spacing)
- Green centerline debug line
- Orbit camera: left-drag rotate, right-drag pan, scroll zoom
- Camera distance clamped to 10-2000m
- Pitch clamped to 5-85 degrees

Updated RoadStudioWidget to use QStackedWidget for 2D/3D view switching:
- Page 0: 2D viewport (MapLibre + road overlay)
- Page 1: 3D viewport (OpenGL mesh)
- Switching is triggered by the toolbar's 2D/3D toggle (Tab key)

Refactored RoadViewport2D to accept store and engine from parent
RoadStudioWidget instead of creating its own, so both 2D and 3D
viewports share the same state.

Added Qt6 OpenGL and OpenGLWidgets modules to CMake.
Linked opengl32.lib on Windows.
