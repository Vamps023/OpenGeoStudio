Auto-create projects in default directory — no folder picker

Project creation no longer asks the user to select a folder.
Just enter the project name and it's created automatically.

Default location: Documents/OpenGeoStudio/Projects/{name}

Flow:
  1. Click "Terrain" or "Road Studio" or "Train Studio" card
  2. Enter project name (dialog)
  3. Project created automatically — no folder selection
  4. Switches to Terrain workspace

Safety: if a project with the same name already exists, shows
a warning and asks for a different name.
