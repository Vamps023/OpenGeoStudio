Add search bar and zoom controls to Road Studio toolbar

Added the same map navigation features that Terrain Studio has
to Road Studio's LaneMaker toolbar:

Search bar:
- Nominatim (OpenStreetMap) geocoding — type a location, press Enter
- Flies the map to the result location (SetMapCenter + ResetCamera)
- Shows the full display name in the search field after selection
- Dark theme styling matching the rest of the toolbar
- Clear button enabled for easy reset

Zoom buttons:
- ➕ Zoom in: 0.85x camera Z (2D) or dolly forward (3D)
- ➖ Zoom out: 1.15x camera Z (2D) or dolly backward (3D)
- "Fit" button: ResetCamera to default view
- Zoom limits preserved: 20m min, 50000m max (2D mode)
- Keyboard shortcuts: Ctrl++ / Ctrl+-

Implementation:
- Added ZoomIn()/ZoomOut() public methods to MapViewGL
  (m_camera was private, so toolbar can't access it directly)
- Zoom logic matches existing wheelEvent behavior exactly
- Search uses QNetworkAccessManager with Nominatim API
- LaneMaker road engine preserved as-is (no changes to road behavior)
