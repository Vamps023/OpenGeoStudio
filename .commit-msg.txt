Add real interactive MapLibre satellite map as 2D background

Replace the single-tile approach with a full MapLibre Native Qt map
widget embedded behind LaneMaker's OpenGL viewport in 2D mode.

Features:
- Full interactive satellite map (pan, zoom, multi-tile loading)
- Esri World Imagery raster tiles (same as Terrain workspace)
- "3D" button toggles between 3D perspective and 2D top-down
- "Map" button activates the satellite map background
- In 2D mode: MapLibre map shows behind, OpenGL renders roads on top
  with transparent background (glClearColor alpha=0)
- In 3D mode: MapLibre hidden, normal LaneMaker 3D rendering

Implementation:
- MainWidget: embedded QMapLibre::MapWidget as background layer
- MainWidget: LmStyleServer (local HTTP server for style JSON)
- MainWidget: setupMapBackground() creates MapLibre widget with Esri style
- MainWidget: toggleViewMode() shows/hides map, toggles OpenGL transparency
- MainWidget: syncMapToCamera() centers map on default location
- MapViewGL: transparent clear in 2D mode (alpha=0) so map shows through
- CMakeLists: linked QMapLibre::Widgets to lanemaker target
- Renamed StyleHttpServer to LmStyleServer to avoid symbol conflict
  with MapViewportWidget's StyleHttpServer
