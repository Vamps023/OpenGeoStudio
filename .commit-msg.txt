Fix road changes not saving — pugixml save_file silently fails on Unicode

The "try direct save first, fallback to temp" approach was flawed:
pugixml's save_file() silently fails on Unicode paths (returns false
but we didn't check it). The old file from a previous temp-copy save
still existed, so QFile::exists() returned true and we logged "saved
directly" — but the file was never actually updated. The file size
stayed at 33658 bytes across multiple saves with different road data.

Fix: always use the temp file approach for saving, same as loading:
  1. Save to temp file in QDir::tempPath() (always ASCII-safe)
  2. Remove old file at destination
  3. QFile::copy from temp to final destination (Qt handles Unicode)
  4. Delete temp file

This is simpler and more reliable than trying to detect whether the
path is ASCII or not. The log now shows the actual file size after
save, so we can verify the content changed.
