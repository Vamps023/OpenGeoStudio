Implement terrain rendering + road visualization in 3D Studio

Terrain rendering:
- OgreWidget::loadTerrain() now creates a real OGRE mesh from a
  heightmap image (PNG/TIFF) with elevation and albedo texture
- Uses ManualObject to build a grid mesh (up to 256x256 vertices)
  sampled from the heightmap, with UV coordinates for albedo
- Albedo texture loaded via TextureGpuManager and applied to an
  Unlit datablock
- Camera auto-frames based on terrain size and height scale
- Terrain size derived from project bounds (4km for Houston-scale)

Road visualization:
- OgreWidget::loadRoads() loads XODR via libOpenDRIVE
- Samples each road's reference line at 1m intervals
- Calculates road width from lane widths
- Generates a triangle strip mesh for the road surface
- Roads placed slightly above terrain (2m offset) to avoid z-fighting

UI:
- Added "Load Roads from Project" button in 3D Studio
- Finds XODR files in project's Roads/ folder

Verified: App launches, 3D Studio opens without crash, OGRE
initializes successfully.
