Fix 3D Studio crash — attach light to SceneNode before setDirection

OGRE-Next 4.0 changed the Light API: lights MUST be attached to a
SceneNode BEFORE calling setDirection(). The Light::setDirection()
documentation says:

  "Light::setDirection and Light::getDirection will redirect to the
   SceneNode and assert or crash if not attached to one."

The crash was an access violation (0xc0000005) in OgreNextMain.dll
because setDirection() was called on a light that wasn't yet attached
to a SceneNode.

Fix:
  - Reorder: create light, set type/colour, create node, attach light
    to node, THEN call setDirection on the node
  - Also removed setupScene() Cube.mesh creation (no mesh files
    deployed yet — terrain loaded separately via loadTerrain())

Verified: App launches, 3D Studio opens, OGRE initializes without
crash, app stays running.
