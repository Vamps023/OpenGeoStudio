Add 3D Studio workspace with O3DE integration

Adds a new "3D Studio" workspace to OpenGeoStudio that integrates
with O3DE (Open 3D Engine) for professional level design.

New workspace:
  Home | Terrain Studio | Road Studio | Train Studio | 3D Studio

3D Studio widget (Studio3DWidget):
  - Launch O3DE Editor with the OpenGeoStudio3D project
  - Launch Game Launcher for testing
  - Export terrain heightmaps from Terrain Studio to O3DE assets
  - Export road network meshes from Road Studio to O3DE assets
  - Real-time O3DE process status and output log
  - Configurable O3DE project and editor paths
  - Auto-detect Editor.exe in common build locations
  - Settings persisted via QSettings

O3DE setup (separate repo at D:/git/o3de):
  - O3DE 2.7.0 cloned and registered
  - OpenGeoStudio3D project created from DefaultProject template
  - CMake configured with PhysX5, Atom, LandscapeCanvas, etc.
  - Build in progress (MSBuild /m parallel)

Architecture:
  OpenGeoStudio (Qt) → 3D Studio workspace → launches O3DE Editor
                                            → exports terrain/road data
  O3DE runs as separate process (cannot be embedded in Qt widget)
