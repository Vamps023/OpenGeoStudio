Phase 4f: Road Studio inspector panel

Added RoadInspector dock widget that shows properties for the selected
road and control point:

Road properties:
- Name (editable text field)
- Width (spin box, 2-30m)
- Lane count (spin box, 1-8)
- Color (color picker dialog)
- Profile type (combo box: city_2x1, city_2x2, country_2x1, highway_2x3, custom)

Control point properties:
- Latitude (spin box, 8 decimal places)
- Longitude (spin box, 8 decimal places)
- Elevation/z (spin box, 3 decimal places)
- Type (combo box: smooth, corner)

The inspector is shown in the right dock widget when Road Studio is
active. It updates live when the selection changes and edits are
applied directly to the store.
