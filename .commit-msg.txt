Fix map Y-coordinate inversion + redesign Road Studio UI

Map fix:
  The tile Y-coordinate mapping was inverted. The code treated +Y as
  south, but OpenGL's ortho projection has +Y = up = north. This made
  tiles appear vertically flipped and in wrong positions.

  Fixed UpdateMapTiles: lat = centerLat + worldY * latPerMeter
  (was: centerLat - worldY * latPerMeter)
  Fixed requestTile: worldY = (tLat - centerLat) / latPerMeter
  (was: (centerLat - tLat) / latPerMeter)

  Also removed leftover debug qDebug line in drawMapBackground.
