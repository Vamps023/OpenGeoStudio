Phase 1.8.3a: roadToV2() adapter — infrastructure + LineSegment conversion

Pure conversion function from legacy Road (ControlPoint[]) to RoadV2
(GeometrySegment[]). This is the seam between the old and new road
engine architectures.

Implemented:
- roadToV2(const Road&) → RoadV2 (pure function, no side effects)
- Metadata copy (id, name, color, profileName, intersection IDs,
  width, laneCount)
- Empty road and single-point degenerate handling
- Corner points (no handles) → LineSegment
- Bezier segments temporarily fall back to LineSegment (TODO 1.8.3b)

Tests (17 new, 171 total, 717 assertions):
- Empty road, single point, one line, two lines, five lines
- Metadata preservation (all 8 fields)
- Pure function invariant (input unchanged)
- Golden parity: straight_2pt (position, heading, curvature, length)
- Golden parity: straight_5pt (segment count, length, positions at
  control points, zero curvature)
- Adapter invariants: segmentCount > 0, totalLength = sum of segments,
  position at s=0 = first point, position at s=totalLength = last point

All 113 vitest tests remain green (no regression).
Legacy Road path is completely untouched.
