Phase 1 Exit: API freeze, benchmarks, architecture docs

Final PR before Phase 2 (Lane Engine). Freezes the Phase 1 public
API, records performance baselines, and documents the architecture
for future contributors.

Changes:
- Doxygen @file/@brief/@section API_Freeze markers added to:
  - geometry_segment.hpp (GeometrySegment, Line/Arc/Spiral/Bezier, SegmentSequence)
  - road_v2.hpp (RoadV2, LaneSection placeholder)
  - road_adapter.hpp (SegmentKind, SegmentMetadata, AdapterReport,
    ReverseAdapterReport, roadToV2/roadToV2Legacy/roadToV2Auto/roadFromV2)
- benchmark.cpp: standalone performance benchmark
  - Measures roadToV2Auto(), sampling, roadFromV2()
  - 100/500/1000 segments × {line, bezier, legacy}
  - Key result: 1000-segment bezier road converts in 75ms, samples in 0.5ms
- docs/ROAD_ENGINE_PHASE1.md: comprehensive architecture reference
  - Layer architecture diagram
  - Ownership model
  - Geometry segment contract
  - Adapter system (exact, legacy, auto-dispatch, inverse)
  - formatVersion migration strategy
  - Bridge & IPC
  - TypeScript types
  - Public API freeze list (frozen vs not-frozen)
  - Performance baseline tables
  - Testing coverage
  - Technical debt & future work (Phases 2-5)
- AGENTS.md: updated to reflect Phase 1 completion
  - Test counts updated (261 doctest, 130 vitest)
  - FROZEN markers on public API headers
  - Link to ROAD_ENGINE_PHASE1.md

API Freeze:
  FROZEN (breaking changes require major version bump):
    - GeometryType, GeometrySegment, LineSegment, ArcSegment,
      SpiralSegment, BezierSegment, SegmentSequence
    - RoadV2
    - SegmentKind, SegmentMetadata
    - AdapterReport, ReverseAdapterReport
    - roadToV2(), roadToV2Legacy(), roadToV2Auto(), roadFromV2()

  NOT FROZEN (will change in Phase 2):
    - LaneSection (empty placeholder)
    - Road::width, Road::laneCount
    - RoadV2::width, RoadV2::laneCount

Performance Baseline (Windows, MSVC release):
  Line 1000:  19.75ms convert, 0.20ms sample, 0.94ms reverse
  Bezier 1000: 75.54ms convert, 0.50ms sample, 2.01ms reverse
  Legacy 1000: 20.21ms convert, 0.32ms sample, 1.29ms reverse

All 261 doctest + 130 vitest pass (no regression).
