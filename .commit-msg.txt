Fix road .xodr not saving with Unicode paths — use temp file fallback

Root cause: GetShortPathNameW returns 0 for non-existent files.
When saving a new road.xodr, the file doesn't exist yet, so the
short path conversion fails. The fallback returns the original
Unicode path, which pugixml's save_file (using fopen) can't handle.

Fix: two-step save approach:
  1. Try saving directly to the target path (works for ASCII paths)
  2. If that fails, save to a temp file in QDir::tempPath() (always
     ASCII-safe), then copy to the final destination using QFile::copy
     (Qt handles Unicode paths natively)

Same approach for loadFromPath:
  1. Try loading directly from the path
  2. If that fails, copy to temp file and load from there

This handles all cases:
  - ASCII paths: direct save/load (fast)
  - Unicode paths: temp file fallback (correct)
  - New files: temp file is created first, then copied
