Export tiles directly to project Terrain folder — no save dialog

The terrain export no longer asks where to save. When you click
Export, tiles are saved directly to:

  {project.basePath}/Terrain/heightmaps/
  {project.basePath}/Terrain/albedo/

If no project is open, it falls back to:
  Documents/OpenGeoStudio/Exports/

This keeps all exported data inside the project folder, so
everything is in one place and the 3D Studio can find it later.
