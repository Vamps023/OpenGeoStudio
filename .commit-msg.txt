Implement 3D object placement + scene serialization + project persistence

3D Object Placement:
- Added SceneObject struct with id, type, name, position, rotation,
  scale, and color
- OgreWidget::addObject() creates a cube mesh for each placed object
  with per-object color (buildings=beige, trees=green, boxes=grey)
- OgreWidget::removeObject(), clearObjects(), updateObjectTransform()
  for full CRUD lifecycle
- Each object has its own OGRE Item + SceneNode

Scene Serialization:
- OgreWidget::saveScene() serializes terrain paths, road path,
  camera state, and all placed objects to JSON
- OgreWidget::loadScene() restores the complete scene from JSON
- Scene saved to {project}/Scene/scene3d.json

Project Persistence:
- Studio3DWidget::onProjectOpened() auto-loads saved scene when
  project is opened (or auto-loads terrain + roads if no scene file)
- Studio3DWidget::onProjectClosed() clears the 3D scene
- main.cpp calls onProjectOpened() when a project is loaded

UI:
- Added "3D Objects" panel with Building/Tree/Box placement buttons
- Added "Scene" panel with Save/Load buttons
- Objects placed at random positions near terrain center

Verified: App launches and runs without crash.
