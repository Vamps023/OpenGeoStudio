Fix roads invisible in 3D + add Blender-style viewport controls

Bug: Roads drawn in 2D were invisible in 3D mode
  Root cause: paintGL only set the perspective projection in
  resizeGL, which is NOT called when switching view modes. So
  switching from 2D to 3D left the projection as ortho, making
  roads appear invisible or distorted in 3D.

  Fix: Set perspective projection every frame in paintGL's 3D
  branch (matching how 2D sets ortho every frame).

  Also improved the default 3D camera angle (35 deg pitch, higher
  altitude) for a better overview of the ground plane.

Blender-style 3D viewport controls:
  - Middle mouse drag = orbit (rotate around target point on ground)
    Yaw = horizontal mouse, pitch = vertical mouse
  - Shift + Middle mouse drag = pan (move along screen plane)
  - Scroll wheel = dolly zoom toward view direction
    (scaled by camera distance for smooth zoom at any scale)

  The orbit rotates the camera position around the ground point
  the camera is looking at, giving intuitive Blender-like behavior.

  Existing controls still work:
  - Right mouse = free rotate (LaneMaker original)
  - WASD = pan, Q/E = rotate Z
  - 2D mode: scroll = zoom in/out, middle = pan
