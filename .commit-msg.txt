Fix Copernicus DEM download URL (404 error)

Three bugs in the Copernicus DEM GLO-30 URL:

1. Wrong corner: tiles are named by SOUTHWEST (lower-left) corner,
   not north/east. Was using tile.bounds.north/east, now uses
   floor(tile.bounds.south/west).

2. Wrong path: S3 key includes a subdirectory with the same name
   as the file. Was: /data/{name}.tif
   Now: {name}/{name}.tif

3. Missing N/S, E/W handling: negative coordinates (southern/western
   hemisphere) now get S/W prefix instead of negative numbers.

Example (Mumbai area, tile covering 18-19N, 72-73E):
  Before: .../data/Copernicus_DSM_COG_10_N19_00_E073_00_DEM.tif → 404
  After:  .../Copernicus_DSM_COG_10_N18_00_E072_00_DEM/Copernicus_DSM_COG_10_N18_00_E072_00_DEM.tif → 200 OK

Verified with curl: HTTP 200 OK, file exists on S3.
