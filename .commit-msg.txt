Completes the four GeometrySegment subclasses (Line, Arc, Spiral, Bezier).

Bug fix (clothoidA):
  clothoidA() divided by (κ₁-κ₀) without abs(). For right-turn spirals
  (κ₁<κ₀), this produced sqrt(negative) = NaN. Fixed to use |κ₁-κ₀|.
  Added test: SpiralSegment with κ₀=0.1, κ₁=-0.1 confirms finite A.

Standing rule applied (per user direction):
  "Any derived quantity that divides by a magnitude computed from control
  points or curvature parameters needs a guard and a degenerate test."
  Applied to:
  - clothoidA(): returns infinity when κ₀==κ₁ (tested)
  - curvatureRate(): returns 0 when κ₀==κ₁ (tested)
  - BezierSegment::curvatureDS(): returns 0 when |B'(t)|<epsilon (tested)
  - BezierSegment::evaluateDS heading: falls back to neighboring t when
    |B'(t)|≈0, then to 0.0 if still degenerate (tested)

BezierSegment implementation (156 lines):
  Storage: P0, P1, P2, P3 absolute control points (Q2 decision)
  Reuses bezierCubic() from geometry.hpp (Bernstein polynomials, equivalent
  to de Casteljau — no reimplementation).
  Arc-length lookup table: N=100 samples, built at construction.
    - s→t via binary search + linear interpolation
    - Construction cost: ~100 bezier evals + 100 distance calcs ≈ μs
    - Interactive editing: 600 tables/sec at 60fps × 10 segments = 1.2% CPU
  Curvature: κ(t) = (B'(t) × B''(t)) / |B'(t)|³
    - Guard: returns 0 when |B'(t)| < EPSILON (cusp at P1==P0 or P2==P3)
    - These are normal editor states (freshly-placed points with no handle)
  Heading: atan2(B'(t).y, B'(t).x), with fallback for zero-velocity cusps
  rebuild() method for mutable use (control point changes)
  clone() deep-copies (rebuilds table from control points)
