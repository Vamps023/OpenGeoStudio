GeoTIFF DEM decoding (DemDecoder::decodeGeoTiff):

- Now uses libtiff directly via TIFFOpen/TIFFReadScanline
- Supports all data types: Float32, Int16, UInt16, Byte
- Reads GDAL nodata tag (TIFFTAG_GDAL_NODATA)
- Uses QTemporaryFile to pass data to libtiff
- Falls back to QImage only for unsupported formats (e.g. RGB TIFF)
