Design decisions (per user direction):
- Storage: startPoint + startHeading + curvatureStart + curvatureEnd + length
  (OpenDRIVE spiral format: κ₀, κ₁, L)
- NO degenerate branching in evaluateDS — SpiralSegment always does the
  general Fresnel math. Degenerate cases (κ₀==κ₁ → Arc, both 0 → Line)
  are handled at the factory/adapter boundary, not inside evaluateDS.
  This avoids discontinuity at epsilon thresholds.
- Derived accessors: clothoidA(), curvatureRate(), totalAngleChange()
- Curvature sign: positive = left/CCW (matching convention on base class)

SpiralSegment math:
  κ(s) = κ₀ + (κ₁ - κ₀) · s / L
  h(s) = startHeading + κ₀·s + (κ₁-κ₀)·s²/(2L)
  position(s) = startPoint + R(θ₀) · ∫₀ˢ [cos(φ(t)), sin(φ(t))] dt
  where φ(t) = κ₀·t + (κ₁-κ₀)·t²/(2L)
  Numerical integration via Simpson's rule (100 subdivisions).
