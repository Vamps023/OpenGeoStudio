Fix crash when switching to Road Studio (OpenGL paintGL recursion)

Root cause: GLBufferManageInstanced::Draw() crashed when vehicle
buffers had no data (m_vertexBufferData empty or m_texture null),
because the OBJ model loading uses assert() which is a no-op in
Release mode. The crash caused the OpenGL context to be recreated,
triggering initializeGL() again, which called Draw() again —
infinite recursion and stack overflow (0xC00000FD).

Fixes:
1. Added guard in GLBufferManageInstanced::Draw() to skip drawing
   when buffers are empty or texture is null
2. Added m_painting recursion guard in MapViewGL::paintGL() to
   prevent reentrant paint calls
3. Reset m_painting flag in initializeGL() on context recreation
